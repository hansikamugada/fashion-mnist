End-to-End Workflow

How It Works

The end-to-end data processing and deep learning pipeline from raw user input to final classification probability.

01

Upload / Capture Image

User provides an image through device upload, camera snapshot, or benchmark samples.

02

Image Preprocessing

Converted to grayscale, aspect-ratio centered, resized to 28×28, and normalized to [0, 1].

03

CNN Model

Deep Convolutional Neural Network processes spatial features across hierarchical layers.

04

Feature Extraction

Conv2D (32 & 64 filters) extract edge, silhouette, texture, and structural patterns.

05

Classification

Flatten and Dense (128 units) with Dropout map feature vectors to 10 class logits.

06

Prediction + Confidence

Softmax activation outputs probability distribution with top category and exact percentage.

Dataset Overview

About the Fashion-MNIST Dataset

Fashion-MNIST is a benchmark dataset created by Zalando Research to serve as a drop-in replacement for the classic MNIST dataset.

70,000

Total Grayscale Images

Standardized, centered clothing articles from modern e-commerce collections.

60,000

Training Images

Used to train convolutional filters and dense weight matrices across multiple epochs.

10,000

Test Images

Held-out evaluation set used to verify unseen generalization and prevent overfitting.

28 × 28

Image Resolution

Single-channel grayscale images normalized into float tensors between 0.0 and 1.0.

Important Project Scope & Limitations Note

Fashion-MNIST consists of low-resolution 28×28 grayscale images. Therefore, predictions on real-world camera photographs may be less accurate than predictions on Fashion-MNIST-like images. Lighting conditions, complex backgrounds, and varying aspect ratios can influence prediction results.
